浏览器的安全模型不会把本机绝对路径交给网页（FileSystemDirectoryHandle.name 只有文件夹名），因此网页选目录后需要把文件上传到本工具的服务端再扫描。 上传副本保存在 audit-tool/workspaces/，仅保留最近 6 份，可随时删除。

适合体量较大的本地仓库：无需上传，服务端直接读取该目录，扫描最快、也最完整。 「浏览目录…」由工具自己列举服务器目录，不依赖 Python 是否自带 tkinter， 任何 Python 3.9+ 环境都可正常选用目录。

检测到当前 Python 解释器未包含 tkinter：系统对话框按钮已隐藏， 请使用「浏览目录…」——功能完全等价，无需安装任何东西。

可移植性

整个 audit-tool/ 目录可直接拷贝到其他电脑运行： 零第三方依赖、路径全部相对化，只需目标机器装有 Python 3.9+。 历史项目档案（projects/）与漏洞库缓存（vulndb/）随包携带，离线可用。 拷到新机器后建议先双击 checkenv.bat（或执行 python app.py --check-env）确认环境就绪。
